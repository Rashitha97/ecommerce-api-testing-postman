# E-Commerce API Testing with Postman

## Project Overview

This project demonstrates REST API testing using Postman and the DummyJSON API.

The test suite covers authentication, user profiles, products, and shopping cart functionality.

## APIs Tested

- Login
- Get User Profile
- Get Products
- Get Single Product
- Add Cart
- Get Cart Details

## Testing Approach

- Positive testing
- Negative testing
- Data-driven testing using CSV files
- Collection Runner
- Environment variables
- API response validation
- HTTP status code validation
- JSON response validation
- Data type validation
- Business logic validation
- Response time validation

## Test Data

CSV files are used for data-driven testing of:

- Login
- Single Product
- Add Cart
